# Funding Performance Analysis using Microsoft Excel

## Project Overview
This project analyzes funding performance across different regions and evaluates lead data quality using Microsoft Excel.

## Objectives
- Analyze total funding by region.
- Calculate average funding by region.
- Compare funding contribution by gender.
- Validate phone number data quality.

## Tools
- Microsoft Excel
- IFS
- SUMIF
- SUMIFS
- AVERAGEIF
- COUNTIF
- IF
- TRIM
- PROPER
- Remove Duplicates
- LEN

## Key Findings
- Jawa Timur recorded the highest total funding balance at 93,870,670, while Sumatera Utara had the lowest total funding balance at 42,021,415,
- Overall, the total funding contributed by male customers (462,722,464) was higher than female customers (416,660,778)
- Bali recorded the highest funding contribution from male customers, totaling 65,245,718
- Only 49% of phone numbers were classified as valid, while 51% were identified as invalid, indicating that improvements in data quality are needed
